## What this is

A (mostly) Jetpack Compose CameraX Android Application that will *eventually* combine all the best features of the best camera apps in the play store, if all goes according to plan, and it will also include all the features that were left out of every camera app that ever existed. It will do so by being open source. The key feature is the plugin system which will allow users and developers alike to add any feature(s) they want.
